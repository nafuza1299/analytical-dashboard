# Tag Playwright checks

## CLI flow

```bash
npm run dev
```

Open the local Vite page and inspect the Tag demo section.

## Suggested checks

- Confirm all six colors use a quiet tinted background with saturated text.
- Toggle light/dark mode and confirm every color remains readable.
- Check `sm` and `md` tags have the specified visual heights.
- Click the red Bug tag’s remove button and confirm it disappears.
- Tab to the remove button and verify its visible focus ring and accessible name.
